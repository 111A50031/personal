## 💻 使用方式

### 本地預覽
直接在瀏覽器中開啟 `index.html` 檔案即可預覽。

### 部署到 GitHub Pages
1. 將此資料夾上傳到 GitHub 上的倉庫
2. 在倉庫設定中啟用 GitHub Pages
3. 選擇主分支作為源
4. 網站將自動部署至 `https://yourusername.github.io`

### 部署到其他平台
- **Netlify**：直接拖曳資料夾上傳
- **Vercel**：連接 GitHub 倉庫自動部署
- **傳統虛擬主機**：上傳 `index.html` 及 `img/` 資料夾即可

## 🛠️ 自定義修改

### 修改個人信息
編輯 `index.html` 中的以下內容：
- `<title>` - 網頁標題
- `謝世香 HSIEH SHIH XIANG` - 姓名
- 個人介紹文字
- 聯絡方式（Email、GitHub、LinkedIn）

### 修改顏色
在 `<style>` 區段中的 `:root` 修改 CSS 變數：
```css
--primary: "#0066cc"         /* 主色調 */
--accent-yellow: "#FFD700"   /* 強調色 */
--accent-blue: "#87CEEB"     /* 輔助色 */
```

### 更換頭像
將新的頭像圖片放到 `img/` 資料夾，並在 HTML 中修改圖片路徑。
